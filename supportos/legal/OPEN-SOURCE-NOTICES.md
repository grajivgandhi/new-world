# SupportOS open-source notices

SupportOS is a commercial product/service layer built around open-source infrastructure.

## Chatwoot

The SupportOS deployment foundation uses the Chatwoot Community Edition container. The current upstream repository describes Chatwoot as released under the MIT License, while its repository also contains separately licensed Enterprise material.

Source: https://github.com/chatwoot/chatwoot

Before distributing modified source or a bundled installation, preserve the applicable upstream copyright and license notices and review the exact version being shipped.

## Branding

SupportOS is an independent product name. Do not use Chatwoot logos, marks, product names or wording in a way that suggests SupportOS is an official Chatwoot product, reseller or endorsed service unless a separate written agreement permits it.

## Dependency audit

Before the first paid release, generate a complete dependency/license inventory for:

- application dependencies
- Docker images
- JavaScript packages
- Ruby gems
- database extensions
- fonts/icons/assets
- third-party APIs and SDKs

This document is an engineering checklist and is not legal advice.
